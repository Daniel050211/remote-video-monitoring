About manual recording

Start and stop a file on the server. The recorder uses the same display frames already prepared for viewers, so the timestamp, MOTION badge, and face boxes may appear in the file. It does not open a second camera. On this project the verified writer is Motion JPEG (MJPG) in an AVI container. That saved file is not the live MJPEG HTTP stream, and it is not H.264 or WebRTC. The writer FPS is the configured container timestamp rate, not a measured capture rate.

Face detection

Detects roughly frontal faces once on the server using an OpenCV Haar cascade (classical Viola-Jones). This is detection only, not recognition or identification: the system draws boxes and reports a count. It does not name or track people. Lighting, pose, and occlusion can cause missed detections or false positives.

Motion detection

Compares consecutive grayscale frames on the server (once, not per viewer). Lighting changes can look like motion. This is not promised false-positive-free.

Transport, limits, and trusted-use notes

Transport: MJPEG over HTTP (a sequence of JPEG images). This is not H.264, H.265, or WebRTC. Video only — no audio.

Configured FPS is the server capture-loop target, not a measured browser display rate. Timestamps use Asia/Hong_Kong (HKT, UTC+8) and are drawn once on the server before JPEG encoding. Snapshots are saved as JPEG files under a server-controlled project folder (data/snapshots/); the browser cannot choose a filesystem path. Motion detection uses grayscale frame differencing with a configured cooldown (default 2.0 s) and a bounded event log; it is not a measured accuracy figure and is not promised false-positive-free. Face detection uses an OpenCV Haar cascade (detection only, not recognition). It runs once on a downscaled copy and every Nth frame (configured trade-off, not a measured FPS). Face boxes may appear in snapshots and recordings because those features use the same display frames. Manual recordings are saved as Motion JPEG (MJPG) in an AVI container under a server-controlled folder (data/recordings/); the browser cannot choose a filesystem path. Windows codec availability has not been verified. Trusted local use only; not a production-secure surveillance system.
